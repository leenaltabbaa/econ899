# Results folder

Every table and figure in the paper and appendix is written here by
`programs/01_main.R`, named after its number and title in the paper (`Table 1 - Summary statistics.csv`,
`Figure 2 - Main event study.png`, ...). Saved model estimates go in `results/estimates/`
and the R session details in `session_info.txt`. These files are generated by the
code and are not included in the repo (see `.gitignore`).
